# CreditDB - アニメ作品・偏差値・制作陣能力評価 Web図鑑

全5,450作品超のアニメ作品の「偏差値」「AniList素点」「Tier」および制作陣（監督・原画・脚本等）のベイジアン実力評価 $S(a)$・キャリアリーダーボードを誰でも軽快に閲覧できる静的Web図鑑・ダッシュボードです。

---

## 主な特徴

1. **シンプルで直感的な3大指標**:
   - **偏差値**: 年代ごとのインフレ・デフレや投票人口バイアスを補正した、同年代内での相対クオリティ（平均50、標準偏差10）。
   - **AniList素点**: 全世界ユーザーによる実レビュー平均点（100点満点）。
   - **Tier**: 偏差値に基づく客観的パーセンタイル階層（Tier S+, Tier S, Tier A+, Tier A...）。
2. **制作陣 能力評価 & リーダーボード**:
   - 監督、シリーズ構成/脚本、キャラクターデザイン、作画監督、原画、演出、音楽、美術監督の全8部門。
   - 各部門の参加作品数中央値 $m_{\text{role}}$（監督: 2.0, 作監: 4.0, 原画: 6.0 等）に基づく高精度ベイズ統計モデルによる実力評価。
   - 総合実力 $S(a)$ 順および生涯通算貢献度 $\Sigma Z$ 順のワンクリック切り替え。
3. **完全な静的Webアーキテクチャ（サーバー不要）**:
   - Python サーバー不要。すべての検索・ソート・フィルタ・モーダル表示がブラウザ上でミリ秒単位で超高速に動作。
4. **月1回の完全自動バックグラウンド更新**:
   - GitHub Actions により、毎月1日にクラウド上で自動的に最新データの収集・再計算・静的ファイル更新が行われます。
